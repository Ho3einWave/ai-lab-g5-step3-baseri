# گام سوم آزمایشگاه هوش مصنوعی — مستندسازی تحلیل اکتشافی داده‌ها

- **گروه:** ۵
- **موضوع پروژه:** تشخیص ژانر موسیقی
- **نقش در این گام:** مستندات
- **تسک:** مستند کردن تحلیل اکتشافی داده‌ها (EDA)، بررسی کیفیت داده و تفسیر نمودارها

این مخزن بخش مستندات گام سوم است. کد بارگذاری داده، اسکریپت تحلیل اکتشافی و نمودارهای اصلی در مخزن
[ai-lab-g5-step3-veiseh](https://github.com/Veiseh/ai-lab-g5-step3-veiseh) قرار دارند. فایل‌های صوتی در این مخزن کپی نشده‌اند؛ فقط جدول فراداده و نمودارها برای بازتولید مستندات آمده‌اند.

## خلاصه گام سوم

| مورد | مقدار |
|---|---|
| مجموعه داده | GTZAN Genre Collection |
| داده بررسی‌شده در این گام | ۱۴ فایل صوتی از ۵ ژانر |
| ژانرها | blues، classical، hiphop، jazz، rock |
| فرمت و مشخصات | WAV، نرخ نمونه‌برداری ۲۲٬۰۵۰ هرتز، تک‌کاناله، ۱۶ بیتی |
| طول هر قطعه | ۳۰ ثانیه (از ۳۰٫۰۰۰ تا ۳۰٫۰۱۳ ثانیه) |
| رکوردهای جدول فراداده | ۱۴ رکورد در ۳ ستون |
| مقادیر گمشده | ۰ |
| رکوردهای تکراری | ۰ |
| ژانر با بیشترین نمونه | hiphop — ۵ فایل (۳۵٫۷۱٪) |
| ژانر با کمترین نمونه | jazz — ۱ فایل (۷٫۱۴٪) |

## یافته‌های کلیدی

1. **توزیع ژانرها متوازن نیست.** hiphop ۳۵٫۷۱٪ داده را دارد و jazz فقط ۷٫۱۴٪. نسبت بیشترین به کمترین نمونه ۵ به ۱ است.
2. **حجم داده برای آموزش مدل کافی نیست.** ۱۴ قطعه در ۵ ژانر، آن هم با یک نمونه jazz، برای تقسیم آموزش/آزمون معنادار کافی نیست. این گام فقط توصیفی است.
3. **فقط ۵ ژانر از ۱۰ ژانر GTZAN بررسی شده‌اند.** نتایج این گزارش به کل مجموعه‌داده یا به یک طبقه‌بند ۱۰ ژانره تعمیم‌پذیر نیست.
4. **همه فایل‌ها WAV هستند.** یکنواختی فرمت باعث می‌شود نمودار فرمت اطلاعات مقایسه‌ای زیادی نداشته باشد، اما برای ادامه کار یعنی داده فعلی از نظر فرمت همگن است.
5. **در سطح فراداده مقدار گمشده یا رکورد تکراری وجود ندارد.** مشکل اصلی کیفیت داده در این مرحله، مسیرهای فایل و کمبود نمونه است، نه گمشدگی یا تکرار.
6. **مسیر فایل‌ها مطلق و ویندوزی است.** هر ۱۴ رکورد مسیرهایی مثل `D:\...\blues.00000.wav` دارند. این مسیرها روی لینوکس، مک یا سیستم اعضای دیگر کار نمی‌کنند.
7. **نمودار مقادیر گمشده از نظر بصری گمراه‌کننده است.** چون همه مقادیر صفرند، محور عمودی به محدوده منفی رفته است. این مشکل داده نیست، مشکل تنظیم محور نمودار است.

## اجرا

برای بازتولید آمار جدول فراداده:

```bash
python3 src/eda_summary.py
```

برای بررسی مشخصات فنی فایل‌های صوتی، مسیر پوشه `genres_original` را هم بدهید:

```bash
python3 src/eda_summary.py --audio-root ../ai-lab-g5-step3-veiseh/data/genres_original
```

اسکریپت فقط از کتابخانه استاندارد پایتون استفاده می‌کند و به نصب pandas یا matplotlib نیاز ندارد. خروجی در `reports/eda_summary.json` ذخیره می‌شود.

برای بازتولید نمودارها، مخزن کد گام سوم را اجرا کنید:

```bash
git clone https://github.com/Veiseh/ai-lab-g5-step3-veiseh.git
cd ai-lab-g5-step3-veiseh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 src/load_data.py
python3 src/eda_visualization.py
```
